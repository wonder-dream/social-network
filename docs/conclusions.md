- 二人协作按“建图组（同学 A：本体/采集/抽取/融合/入库）”与“应用组（同学 B：GraphRAG/Streamlit/对比评测）”解耦，接口为标准化 CSV 与 Neo4j Schema [[26-11-26-15-立项与调研留痕]]
- 30% 论文调研报告需个人独立提交，两人分别侧重“医疗 KG 自动构建与融合”与“医疗 GraphRAG 与幻觉抑制”以避免撞车 [[26-11-26-15-立项与调研留痕]]
- 数据采集采用 `QASystemOnMedicalKG` 常见病子集 + 中文维基 MediaWiki API 双源方案，既满足爬虫与融合要求又避免反爬折腾 [[26-11-26-15-立项与调研留痕]]
- 图数据库驱动明确采用官方 `neo4j` Python 包替代已废弃的 `py2neo`，前端可视化采用 `Streamlit + PyVis` [[26-11-26-15-立项与调研留痕]]
