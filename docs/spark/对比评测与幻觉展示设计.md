# 对比评测与幻觉展示设计

- **思路**：不用跑复杂自动评测脚本，只需精选 15~20 道常见病问答测试题，按 4 类场景（单跳属性查询、症状反查常见病、明确饮食宜忌、图谱外长尾问题兜底）跑一遍“纯大模型”和“轻量 GraphRAG”，用人工核对 + 3 个维度（事实准确率、是否编造/遗漏禁忌、是否展示图谱证据）打分，就能在 60% 技术报告里做出非常有科研感的定量对比表与案例截图。
- **完成度**：构思阶段（10%，待图谱入库与问答链路打通后落地执行）

## 建议题型配比（共 20 题）

1. **单跳事实查询（6 题）**：如“急性胃炎通常需要做哪些检查？”“高血压日常忌吃什么食物？”
2. **症状反查推理（5 题）**：如“经常鼻塞、流涕、打喷嚏，常见可能是哪些病，建议做什么检查？”（天然展示 2 跳路径：`Symptom ← Disease → Check`）
3. **多维综合科普（5 题）**：如“2 型糖尿病在饮食上哪些宜吃、哪些忌吃，常见参考用药有哪些？”
4. **未收录词条边界测试（4 题）**：问 50 种常见病以外的罕见病或偏门药，验证系统是否如实触发兜底提示、不伪造图谱证据。

## 报告呈现建议

- 放 1 张汇总指标表（纯 LLM vs GraphRAG 在 20 题上的事实准确率、禁忌覆盖率、证据可追溯率）；
- 放 3 组典型截图对比，重点高亮 GraphRAG 在“给出结构化三元组证据”和“精准指出忌口/检查项”上的直观优势。
