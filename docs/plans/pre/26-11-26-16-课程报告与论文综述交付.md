# 26-11-26-16 课程报告与论文综述交付

## 目标
在课程结束后一周内按时提交全部考核材料：两人各自独立的《论文调研报告》（30%）与两人共用的《实践作业技术报告 + 代码 + 数据》（60%）。

## 步骤
1. **个人 30% 论文调研报告（各自独立撰写）**：
   - 同学 A 撰写《面向医疗健康领域的知识图谱自动构建与融合技术研究综述》（聚焦 LLM 抽取、医学实体对齐）；
   - 同学 B 撰写《知识图谱增强大模型（GraphRAG）在医疗问答中的研究进展》（聚焦 GraphRAG、幻觉抑制、医疗推理评测）；
   - 每份精读并引用 10~15 篇近三年顶会/期刊论文，包含 1 张核心方法横向对比表与“对实践项目的启发”小节。
2. **共同 60% 实践作业技术报告（按 6 大模块拼接）**：
   - 同学 A 撰写：第 1 章项目概述与分工、第 2 章本体建模（附本体图）、第 3 章双源数据采集清洗与大模型抽取、第 4 章知识融合（附融合统计表）与 Neo4j 图存储（附可视化截图）；
   - 同学 B 撰写：第 5 章轻量 GraphRAG 大模型增强设计、第 6 章 Streamlit 智能应用展示（附界面截图）、第 7 章基线对比测试与总结。
3. **代码与数据打包核验**：
   - 清理 `.env` 与本地临时缓存，补充 `.env.example`、`requirements.txt` 与一键运行说明至 `README.md`；
   - 在干净环境复测导入脚本与 `streamlit run app.py`，确认无缺包或硬编码密钥后打包上传课程云平台（两人提交相同实践压缩包）。

## 判据
- 两份 30% 论文调研报告视角独立、文献引用真实可查、格式规范；
- 60% 技术报告完整覆盖课程要求的全部 6 个模块，图文与数据统计表齐全；
- 提交的代码包不含任何真实 API Key 或 Neo4j 密码，附带清晰复现步骤。

## 取舍
- 不追求学术论文投稿级的大规模消融实验，聚焦把 6 个必考模块做全、做实、有图有表有对比，确保高性价比稳过。
