# 01-架构

## 系统定位

面向常见病健康科普场景的轻量级知识图谱构建与增强问答系统，用于完整覆盖知识图谱课程作业的 6 项实践要求，并为两人各自独立的论文调研报告提供实践对照。

## 总体链路

```text
多源原始数据（开源常见病结构化子集 + 维基百科科普文本）
        │
        ▼
[1. 本体建模] 定义常见病核心概念与关系规范
        │
        ▼
[2. 图谱构建] 清洗筛选 + 科普文本采集 + 大模型三元组抽取
        │
        ▼
[3. 知识融合] 多源实体对齐、别名归一、重复边消解
        │
        ▼
[4. 知识存储] 导入图数据库并建立唯一约束与查询视图
        │
        ▼
[5. 大模型增强] 问题实体抽取 → 子图检索 → 图谱事实注入生成（轻量 GraphRAG）
        │
        ▼
[6. 智能应用] 图谱检索与可视化 + 证据可追溯的健康科普问答界面 + 基线对比评测
```

## 两人解耦边界

- **建图侧（同学 A）**：负责上游环节（1~4），最终交付稳定的图谱本体规范、多源融合后的标准数据表以及可查询的图数据库实例。
- **应用侧（同学 B）**：负责下游环节（5~6），基于约定好的图谱本体直接开发检索增强问答、交互界面与基线对比实验，开发初期可用少量样例图谱并行联调。
- **独立调研（30% 作业，两人分开撰写）**：同学 A 聚焦“医疗知识图谱自动构建与融合”，同学 B 聚焦“医疗 GraphRAG 与大模型幻觉抑制”，共用课程主题但视角互斥、互不查重。
