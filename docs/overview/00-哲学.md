# 00-哲学

1. **够用稳过，拒绝过度工程**
   这是 2 人协作的课程大作业，不追求复杂分布式架构，也不自行训练 NER/RE 模型。优先选用成熟、轻量、低调试成本的工具链，把精力集中在把 6 个考核环节完整跑通并产出清晰证据（图谱截图、融合统计表、问答对比案例）。

2. **小而精的数据边界**
   与其灌入数万个脏节点把图谱和演示卡死，不如精选 **50 种常见病**，保证本体清晰、来源真实多源、实体对齐可复现、可视化直观。

3. **双向大模型增强**
   将大模型放在最省力且最有说服力的两个位置：建图阶段用大模型 JSON 模式抽取三元组（LLM → KG），问答阶段用轻量 GraphRAG 检索子图约束回答（KG → LLM）。

4. **两人解耦，接口先行**
   同学 A（建图组）与同学 B（应用组）以“标准化节点/关系 CSV + Neo4j 图谱 Schema”为唯一契约，双方可完全并行开发。

5. **科普定位，严守医疗边界**
   系统定位为**健康科普问答**而非临床诊断工具；检索无结果时明确兜底，严禁编造药物剂量或替代医生决策。
